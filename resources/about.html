This is not a DeepSeek product. Harness Desktop is an unofficial, community-built desktop shell around DeepSeek Harness — DeepSeek AI's open-source agent harness, MIT licensed.

The entire chat interface, the agent and the tools inside this app are upstream's work. This project does not modify that source code; it contributes only the shell: process lifecycle, windows, the system tray, notifications and the installer.

The shell is released under the MIT license. Upstream's third-party dependency list lives in THIRD_PARTY_NOTICES.md in the original repository.
